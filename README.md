# Ulil Albab: Quran

## About
Ulil Albab is a Quran application that helps users read and understand the Quran.

## Features
- Read Quran with translation (currently only Bahasa Indonesia by Kemenag-RI)

### TODO
- Search verses
- Bookmarks
- Murottal

## Version
0.0.1

## Prerequisite
- node.js >= 18
- XCode & ioS Simulator
- Android Studio & Android Emulator

## Install
```
yarn install
npx expo prebuild
```

## Usage
```
yarn start    # expo start for web/ios
yarn android  # expo run android
yarn ios      # expo run ios only
```
